ANONYVERSE website deployment bundle

Checkpoint: 284f85965b9ed1eeefe5e71800ffa6333b5db72d

Recommended Vercel setup:
1. Import this repository or upload this bundle to your Git provider.
2. Set Root Directory to apps/web.
3. Framework preset: Next.js.
4. Build command: pnpm build.
5. Install command: pnpm install --frozen-lockfile (run from repository root when using the full monorepo).
6. Keep provider credentials and backend secrets out of NEXT_PUBLIC_* variables.

The website currently runs on fictional demo content and uses bundled artwork under apps/web/public/artwork. It does not require a production secret to build.
