ANONYVERSE full source bundle

Checkpoint: 3cc29ca63bbf43afa9e52272490467cdfa6a8693

Contains the preserved Expo mobile app, Express/tRPC backend, Drizzle schema, Next.js website, shared packages and release documentation.

Install dependencies with:
  pnpm install --frozen-lockfile

Validate with:
  pnpm check && pnpm lint && pnpm test && pnpm web:build

The managed mobile runtime remains Expo 8081 plus API 3000. The website can be deployed separately from apps/web to Vercel.
